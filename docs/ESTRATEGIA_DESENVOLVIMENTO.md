# 🇬🇧 Salonix Backend Development Strategy (EN)

## Overview
This document outlines the phased strategy to take the Salonix Backend from MVP to production. It focuses on core readiness, real communications, billing/paywall enforcement, observability, and operational excellence.

## Phases
- Phase 1 — MVP Core: multi-tenant scheduling, reports, branding, admin, validation, error handling, tests.
- Phase 2 — Real Communications: Twilio SMS (BE-128), WhatsApp (Meta) (BE-129), Portuguese phone validation (BE-130).
- Phase 3 — Billing & Plans: Stripe live mode, plan enforcement, theme preference persistence.
- Phase 4 — Observability & Ops: metrics, alerts, dashboards, runbooks, incident response.
- Phase 5 — Post-MVP Enhancements: performance, i18n, audit logs, advanced analytics.

# 🇧🇷 Estratégia de Desenvolvimento do Backend (PT)

## Visão Geral
Este documento descreve a estratégia por fases para levar o Backend do Salonix do MVP à produção. Foco em prontidão core, comunicações reais, billing/paywall, observabilidade e excelência operacional.

## Fases
- Fase 1 — MVP Core: agendamentos multi-tenant, relatórios, branding, admin, validação, tratamento de erros, testes.
- Fase 2 — Comunicações Reais: SMS Twilio (BE-128), WhatsApp (Meta) (BE-129), validação telefones PT (BE-130).
- Fase 3 — Billing & Planos: Stripe live, enforcement de planos, persistência de preferência de tema.
- Fase 4 — Observabilidade & Ops: métricas, alertas, dashboards, runbooks, resposta a incidentes.
- Fase 5 — Pós-MVP: performance, i18n, auditoria, analytics avançados.
